# Green Guardian 🌱

Green Guardian is a web application built using **Flutter Web** that promotes environmental awareness and encourages users to take eco-friendly actions.

## 🚀 Technologies Used

* **Frontend:** Flutter Web
* **Programming Language:** Dart
* **UI Framework:** Material Design
* **Backend:** Firebase
* **Database:** Cloud Firestore
* **Hosting:** Firebase Hosting
* **Version Control:** Git & GitHub

## ✨ Features

* User-friendly interface
* Environmental awareness content
* Firebase database integration
* Responsive web design

## 🛠 Installation

1. Clone the repository

```
git clone https://github.com/Bhanusreeyadav/green-guardian.git
```

2. Navigate to project folder

```
cd green-guardian
```

3. Get dependencies

```
flutter pub get
```

4. Run the application

```
flutter run -d chrome
```
